   # DGS MetaHuman (Unreal Engine 5.8.4)

   MetaHuman version of the DGS sign language avatar.

   ## Setup
   1. Install Unreal Engine 5.8.4 with "MetaHuman Creator Core Data".
   2. Clone this repo.
   3. Download the MetaHuman assets (too big for GitHub): [LINK](https://drive.google.com/file/d/1truhm6fAXBpxD2UJxfcudM7SIrnbsSsJ/view?usp=sharing)
   4. Unzip them into `Content/`, so you get `Content/MetaHumans` and `Content/Characters`.
   5. Open `DGSMetaHuman.uproject`. The start level is `Content/Maps/SignerLevel`.
